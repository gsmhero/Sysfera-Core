Manual for AgentsИнструкция для Агентов

An Agent runs his own Sysfera site, registers users and sellers on it, connects it to the Basebase marketplace and earns an Agency fee (a share of the platform commission) on every sale of his sellers.Агент ведёт собственный сайт на Sysfera, регистрирует на нём пользователей и продавцов, подключает его к маркетплейсу Basebase и получает агентское вознаграждение (часть комиссии платформы) с каждой продажи своих продавцов.

  1. Prepare hostingПодготовьте хостинг

    You need a domain or sub-domain with HTTPS, PHP 8.1+ (pdo_mysql, mbstring, zip) and one empty MySQL database. HTTPS and a public domain name are required by Messenger and the Basebase connector.Нужен домен или поддомен с HTTPS, PHP 8.1+ (pdo_mysql, mbstring, zip) и одна пустая база MySQL. HTTPS и публичное доменное имя нужны для Messenger и подключения к Basebase.

  2. Install the coreУстановите ядро

    Upload sysfera-install.php to the domain folder by FTP, open https://your-domain/sysfera-install.php, press Unpack and continue and follow the wizard: server check → database → site name and administrator. At the end delete install.php.Загрузите sysfera-install.php в папку домена по FTP, откройте https://ваш-домен/sysfera-install.php, нажмите «Распаковать и продолжить» и пройдите мастер: проверка сервера → база данных → название сайта и администратор. В конце удалите install.php.

  3. Install componentsУстановите компоненты

    Sign in → Components → install WMS and WMS → Basebase (and, if you like, Messenger, Activity, News).Войдите → Компоненты → установите WMS и WMS → Basebase (и при желании Messenger, Activity, Новости).

  4. Open registration for your usersОткройте регистрацию для своих пользователей

    Settings → tick Allow visitors to register themselves and choose what new users may use. Visitors who are not signed in will see the Sysfera home page with Create account and Sign in buttons.Настройки → отметьте «Разрешить посетителям регистрироваться» и выберите, чем смогут пользоваться новые пользователи. Посетители без входа увидят главную страницу Sysfera с кнопками «Создать аккаунт» и «Войти».

  5. Get your AGENT_KEYПолучите AGENT_KEY

    Open Basebase → Connection in your Sysfera: the page shows the AGENT_KEY (created automatically).Откройте Basebase → Подключение в вашем Sysfera: на странице показан AGENT_KEY (создаётся автоматически).

  6. Become an Agent on BasebaseСтаньте Агентом на Basebase

    Register at basebase.ru, switch the account type to Agent (Settings), open Cabinet → Partner site, enter your site address and the AGENT_KEY and press Save connection. Agents are approved automatically; the Basebase administrator may suspend an Agent later.Зарегистрируйтесь на basebase.ru, переключите тип аккаунта на Агент (Настройки), откройте Кабинет → Партнёрский сайт, введите адрес сайта и AGENT_KEY и нажмите «Сохранить подключение». Агенты подтверждаются автоматически; администратор Basebase может позже приостановить Агента.

  7. Copy the API access backПеренесите доступ к API обратно

    On the same Basebase page copy Agent ID, API address and API secret into Sysfera → Basebase → Connection and press Test connection. Keep the secret private.На той же странице Basebase скопируйте Agent ID, адрес API и API secret в Sysfera → Basebase → Подключение и нажмите «Проверить подключение». Храните секрет в тайне.

  8. Create a sellerСоздайте продавца

    On the Connection page press Create seller: a Supplier account linked to you is created and its Seller ID is filled in. (Or ask the Basebase administrator to assign an existing seller to you.)На странице подключения нажмите «Создать продавца»: создаётся аккаунт поставщика, привязанный к вам, а Seller ID подставляется сам. (Или попросите администратора Basebase закрепить за вами существующего продавца.)

  9. Publish products and take ordersПубликуйте товары и принимайте заказы

    In WMS add products, tick the ones to sell on Basebase, choose the warehouse whose available stock is sold. Stock syncs after every document; new Basebase orders arrive in WMS automatically. All commissions are set in Basebase, not in the connector.В WMS добавьте товары, отметьте те, что продаются на Basebase, выберите склад, чей доступный остаток продаётся. Остатки синхронизируются после каждого документа; новые заказы Basebase попадают в WMS автоматически. Все комиссии задаются в Basebase, а не в коннекторе.

Your earnings. Your Agency fee is a percentage of the margin (selling price − supplier price) on every sale of your sellers. It is part of the platform commission, so sellers and bloggers never pay more. The money arrives in your Basebase wallet when the order item is marked Delivered.Ваш заработок. Агентское вознаграждение — процент от маржи (цена продажи − цена поставщика) с каждой продажи ваших продавцов. Оно входит в комиссию платформы, поэтому продавцы и блогеры не платят больше. Деньги поступают в кошелёк Basebase, когда позиция заказа отмечена как «Доставлено».

For usersПользователям

You do not install anything. Open the site of your Agent, press Create account, register with your e-mail and start working.Ничего устанавливать не нужно. Откройте сайт вашего Агента, нажмите «Создать аккаунт», зарегистрируйтесь по e-mail и начинайте работать.
